Pacchi d'api

Il pacco d'api contiene api giovani ed è la soluzione ideale per diverse esigenze di apicoltura. Può essere utilizzato con regina per costituire una nuova famiglia, oppure senza regina per rimpolpare le famiglie esistenti in vista della partenza primaverile.

È una soluzione leggera, ideale sia per chi vuole avviare una nuova attività o ampliare l'apiario, sia per chi desidera rafforzare le proprie arnie prima dell'inizio della stagione, con costi di trasporto contenuti.

Prepariamo i pacchi su ordinazione, indicandoti i tempi di introduzione e i primi accorgimenti per l'avvio o il rinforzo della famiglia.
